⚠️ NOTA: DETALHAMENTO DE MENSAGENS DE ERRO 
 
As validações processadas pelo sistema da DeRE retornam mensagens de erro ao contribuinte sempre que alguma regra técnica ou de 
negócio é violada. O texto literal e o detalhamento das mensagens de erro estão consolidados no documento ‘08-Mensagens de Erro 
do Sistema’. 
 
O Comportamento do Sistema de Validação (Interrupção de Processamento): 
O indicativo de interrupção define o comportamento do sistema da DeRE ao identificar um erro. Independentemente da indicação de 
interrupção (Sim/Não), qualquer erro resulta na recusa integral do evento  (o sistema não grava a informação na base de dados e 
devolve o status {cdRetorno} = [0]). 
A distinção aplica-se à continuidade da trilha de validação: 
• Interrompe o processamento: [Sim] (erro crítico/estrutural): O processamento é abortado imediatamente no exato ponto da 
falha. Não são avaliadas as regras ou campos subsequentes. O arquivo de retorno exibirá a ocorrência que provocou a parada do  
sistema, acompanhada de eventuais erros acumulativos já registrados nas etapas anteriores à interrupção; 
• Interrompe o processamento: [Não] (erro acumulativo): O processamento não é abortado no momento da falha. O sistema 
registra a inconsistência e continua executando a trilha de validação até a leitura final do arquivo (desde que não encontre um erro crítico 
no caminho). O arquivo de retorno exibirá a listagem consolidada dos erros acumulados ao longo do evento.

DV_CNPJ O dígito verificador indicado no CNPJ deve corresponder ao calculado conforme a regra abaixo: 
1. Fórmula de Conversão: 
Valor = Código_ASCII(Caractere) - 48 
Números (0-9): Permanecem com os valores de 0 a 9. 
Letras (A-Z): Assumem valores decimais de 17 a 42 (Ex: A=17, B=18...). 
2. Algoritmo de Cálculo (Módulo 11): 
O cálculo utiliza dois conjuntos de pesos para determinar os dois últimos dígitos. 
 Primeiro Dígito (DV1 - Posição 13) 
Pesos aplicados às 12 primeiras posições: 5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2. 
Segundo Dígito (DV2 - Posição 14) 
Pesos aplicados às 13 primeiras posições (incluindo DV1): 6, 5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2. 
2.1 Lógica do Dígito: 
- Calcular a Soma dos produtos (Valor × Peso). 
- Calcular o Resto = Soma mod 11. 
- Calcular o Dígito = 11 - Resto. 
 Se o Dígito ≥ 10, o valor final é 0. 
(Mensagem de erro: MS1239 - Interrompe o processamento: Não) 
Exemplo (CNPJ: ABC123450001-XX): 
• DV1: Valores=(17, 18, 19, 1, 2, 3, 4, 5, 0, 0, 0, 1) x Pesos=(5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2). Soma = 318. Resto 
= 318 mod 11 = 10. DV1 = 11 - 10 = 1. 
• DV2: Valores=(17, 18, 19, 1, 2, 3, 4, 5, 0, 0, 0, 1, 1) x Pesos=(6, 5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2). Soma = 374. 
Resto = 374 mod 11 = 0. DV2 = 11 - 0 = 11 (Como ≥ 10, DV2 = 0). CNPJ Validado: ABC123450001-10.

RN - Unicidade Recepção Evento 1. A identificação única do evento (Id) é composta por 42 caracteres, conforme abaixo: 
DeRENNNNTXXXXXXXXXXXXXXAAAAMMDDHHMMSSQQQQQ 
DeRE - Texto fixo. Identifica o evento da DeRE. Respeitar maiúsculas e minúsculas. 
NNNN - Código do Evento sendo transmitido (ex: 1001, 1011, 1101 etc.). 
T - Tipo de Inscrição do Contribuinte (1 - CNPJ). 
XXXXXXXXXXXXXX - Número da Inscrição (CNPJ) do declarante. CNPJ Alfanumérico (A -Z, 0-9), letras 
devem ser convertidas para MAIÚSCULAS completado com zeros à esquerda. 
AAAAMMDD - Data da geração do arquivo (Ano, Mês, Dia). 
HHMMSS - Hora da geração do arquivo (Hora, Minuto, Segundo). Fuso Horário: Brasília (UTC-3). 
QQQQQ - Sequencial numérico (00001 a 99999). Utilizado para garantir unicidade caso sejam gerados 
múltiplos arquivos no mesmo segundo. 
(Mensagem de erro: MS1050 - Interrompe o processamento: Sim)
